Lecture 09

Differentiation & Derivative Rules

From the limit definition of slope to the full toolkit of differentiation — power, product, quotient, and chain rules for every function you will meet.

// Section 1

Line Equation Review

Before derivatives, recall that the slope of a line through two points (x₁, y₁) and (x₂, y₂) is:

m = (y₂ − y₁)/(x₂ − x₁)

The point-slope form with slope m through (x₁, y₁):

y − y₁ = m(x − x₁)
Example

Find the equation of the line through (1, 4) and (5, 12).

m = (12 − 4)/(5 − 1) = 8/4 = 2

y − 4 = 2(x − 1) → y = 2x + 2

// Section 2

The Derivative

Limit Definition

For a function y = f(x), its derivative at x is:

f′(x) = limh→0 [f(x+h) − f(x)]/h

If this limit exists, we say f is differentiable at x.

Geometrically, the derivative is the instantaneous rate of change — the slope of the tangent line at a point, obtained by letting the secant line between two nearby points collapse to a single point.

// Secant line → Tangent line as h → 0
Notation

The derivative can be written in many equivalent ways:

f′(x)    or    d/dx f(x)    or    y′    or    dy/dx

Examples from the Definition

Example 1 — f(x) = 3x + 5

f(x+h) = 3(x+h) + 5 = 3x + 3h + 5

[f(x+h) − f(x)]/h = [3x + 3h + 5 − 3x − 5]/h = 3h/h = 3

f′(x) = limh→0 3 = 3

Example 2 — f(x) = x²

[f(x+h) − f(x)]/h = [(x+h)² − x²]/h = [2xh + h²]/h = 2x + h

f′(x) = limh→0 (2x + h) = 2x

// Section 3

Basic Differentiation Rules

Instead of using the limit definition every time, we have rules that let us differentiate instantly.

Constant & Power Rules

Rule 1 — Constant Rule d/dx(c) = 0

The derivative of a constant is zero — its graph is a horizontal line with no change.

Rule 2 — Power Rule d/dx(xⁿ) = n·xⁿ⁻¹

For any real number n. This is the most frequently used rule in calculus.

Power Rule Examples

d/dx(x³) = 3x²

d/dx(x^(2/3)) = (2/3)x^(−1/3)

d/dx(1/x⁴) = d/dx(x^(−4)) = −4x^(−5)

d/dx(√x) = d/dx(x^(1/2)) = (1/2)x^(−1/2) = 1/(2√x)

Sum, Difference & Constant Multiple

Rule 3 — Constant Multiple Rule d/dx [c·f(x)] = c·f′(x)
Rule 4 — Sum & Difference Rules d/dx [f(x) ± g(x)] = f′(x) ± g′(x)
Worked Example

Differentiate f(x) = 2x⁵ + 7

f′(x) = d/dx(2x⁵) + d/dx(7) = 2·5x⁴ + 0 = 10x⁴

Example — Polynomial

Differentiate y = x⁸ + 12x⁵ − 4x⁴ + 10x³ − 6x + 5

y′ = 8x⁷ + 60x⁴ − 16x³ + 30x² − 6

// Section 4

Exponential & Logarithmic Rules

Natural Exponential
d/dx(eˣ) = eˣ
The function eˣ is its own derivative — unique and essential.
Natural Logarithm
d/dx(ln x) = 1/x
For x > 0. More generally: d/dx[ln f(x)] = f′(x)/f(x).
General Exponential
d/dx(aˣ) = aˣ·ln a
Example: d/dx(2ˣ) = 2ˣ·ln 2.
General Logarithm
d/dx(logₐ x) = 1/(x ln a)
Derived from the change-of-base formula.
Example — Combined

If f(x) = eˣ − x, then f′(x) = eˣ − 1.

// Section 5

Product & Quotient Rules

Product Rule d/dx [f(x)·g(x)] = f(x)·g′(x) + g(x)·f′(x)
Example — Product Rule

Let f(x) = x·eˣ.

f′(x) = x·d/dx(eˣ) + eˣ·d/dx(x) = x·eˣ + eˣ·1 = (x + 1)eˣ

Quotient Rule d/dx [f(x)/g(x)] = [g(x)·f′(x) − f(x)·g′(x)] / [g(x)]²
Example — Quotient Rule

Let y = (ln x)/x³.

y′ = [x³·(1/x) − (ln x)·3x²] / x⁶ = [x² − 3x²·ln x] / x⁶ = (1 − 3 ln x)/x⁴

// Section 6

The Chain Rule

The Chain Rule is for composite functions — functions inside functions. It is the most powerful rule in differentiation.

Chain Rule

If y = f(g(x)), then:

dy/dx = f′(g(x)) · g′(x)

In words: "derivative of the outside (evaluated at the inside) × derivative of the inside."

Special Cases of the Chain Rule

General Power
d/dx [g(x)]ⁿ = n[g(x)]ⁿ⁻¹ · g′(x)
Example: d/dx (x³ − 1)^100 = 100(x³ − 1)^99 · 3x² = 300x²(x³ − 1)^99
Exponential Chain
d/dx e^(g(x)) = e^(g(x)) · g′(x)
Example: d/dx e^(5x) = 5e^(5x).   d/dx e^(x²+1) = 2x·e^(x²+1)
Logarithmic Chain
d/dx ln(g(x)) = g′(x) / g(x)
Example: d/dx ln(x³ + 1) = 3x²/(x³ + 1)
General Exponential Chain
d/dx a^(g(x)) = a^(g(x)) · ln a · g′(x)
Example: d/dx 3^(2x²) = 3^(2x²) · ln 3 · 4x
// Section 7

Higher Derivatives

The derivative of a derivative is the second derivative, denoted f″(x) or d²y/dx². We can continue indefinitely:

f′(x) → f″(x) → f‴(x) → f⁽⁴⁾(x) → … → f⁽ⁿ⁾(x)
Example

Let y = x³ − 3x² + 2

y′ = 3x² − 6x

y″ = 6x − 6

y‴ = 6

y⁽⁴⁾ = 0
