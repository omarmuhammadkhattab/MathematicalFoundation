Extrema, Partial Derivatives
& Integration

Applying derivatives to find peaks and valleys, extending to functions of several variables, and reversing differentiation through integration.

// Section 1

Local Maximum & Minimum Values

A continuous function may rise to a peak (local maximum) or dip to a valley (local minimum). These are called local extrema or turning points.

Critical Points

Points where f′(x) = 0 are called stationary points or critical points. At these points the tangent line is horizontal.

Not every critical point is an extremum — some are inflection points where the curve merely flattens out before continuing in the same direction.

// f(x) = sin x — multiple local maxima and minima

The Second Derivative Test

Once you find a critical point x = a where f′(a) = 0, the second derivative tells you what kind of point it is:

Local Maximum
f″(a) < 0
The curve is concave down at a — like the top of a hill.
Local Minimum
f″(a) > 0
The curve is concave up at a — like the bottom of a valley.
Inconclusive
f″(a) = 0
Could be max, min, or inflection. Use the first derivative test or higher derivatives.
Worked Example

Find the local extrema of f(x) = 2x³ − 21x² + 36x − 20

// Step 1 — Find critical points
⟹f′(x) = 6x² − 42x + 36 = 6(x − 1)(x − 6)
⟹f′(x) = 0 → x = 1 or x = 6
// Step 2 — Second derivative test
⟹f″(x) = 12x − 42
⟹f″(1) = 12 − 42 = −30 < 0local maximum
⟹f″(6) = 72 − 42 = 30 > 0local minimum
// Step 3 — Function values
⟹f(1) = 2 − 21 + 36 − 20 = −3
⟹f(6) = 432 − 756 + 216 − 20 = −128
Local Max: (1, −3)    Local Min: (6, −128)

Partial Derivatives

For a function of two variables f(x, y), we differentiate with respect to one variable while treating the other as a constant.

Definition

The partial derivative of f(x,y) with respect to x is written ∂f/∂x and found by differentiating f with respect to x while holding y constant.

Example 1

Let f(x,y) = 5x³y²

∂f/∂x = 15x²y²   (treat y² as a constant coefficient)

∂f/∂y = 10x³y   (treat x³ as a constant coefficient)

Example 2 — Chain Rule for Partials

Let f(x,y) = (4x + 3y − 5)⁸

∂f/∂x = 8(4x + 3y − 5)⁷ · 4 = 32(4x + 3y − 5)⁷

∂f/∂y = 8(4x + 3y − 5)⁷ · 3 = 24(4x + 3y − 5)⁷

Indefinite Integration

Integration is the reverse of differentiation. The result of indefinite integration is a family of functions (all differing by a constant).

Definition ∫ f(x) dx = F(x) + C

where F′(x) = f(x) and C is the constant of integration.

Basic Integration Rules

RuleFormula
Constant∫ k dx = kx + C
Power (n ≠ −1)∫ xⁿ dx = xⁿ⁺¹/(n+1) + C
Reciprocal∫ 1/x dx = ln|x| + C
Natural Exponential∫ eˣ dx = eˣ + C
Constant Multiple∫ k·f(x) dx = k·∫ f(x) dx
Sum/Difference∫ [f(x) ± g(x)] dx = ∫ f(x) dx ± ∫ g(x) dx
Examples

∫ 7x dx = 7·x²/2 + C = (7/2)x² + C

∫ 1/√t dt = ∫ t^(−1/2) dt = t^(1/2)/(1/2) + C = 2√t + C

∫ (2x^(4/5) − 7x³ + 10eˣ − 1) dx = (10/9)x^(9/5) − (7/4)x⁴ + 10eˣ − x + C

Definite Integration

A definite integral computes a number — specifically, the net area under the curve y = f(x) from x = a to x = b.

Fundamental Theorem of Calculus ∫ab f(x) dx = F(b) − F(a)

where F is any antiderivative of f. We often write F(b) − F(a) = [F(x)]ab.

// Definite integral = signed area under f(x) from a to b
Worked Example

Evaluate ∫−13 (3x² − x + 6) dx

Antiderivative: F(x) = x³ − x²/2 + 6x

F(3) = 27 − 9/2 + 18 = 45 − 4.5 = 40.5

F(−1) = −1 − 1/2 − 6 = −7.5

F(3) − F(−1) = 40.5 − (−7.5) = 48
