Lecture 08

Limits & Their Techniques

The bridge between algebra and calculus — understanding how functions behave as inputs approach a point, with numerical, graphical, and algebraic techniques.

// Section 1

What is a Limit?

Definition

If f(x) becomes arbitrarily close to a unique number L as x approaches c from either side, then the limit of f(x) as x approaches c is L.

limx→c f(x) = L

The limit describes the destination the function is heading toward, not necessarily the value it actually reaches at x = c.

Classic Example

How does f(x) = (x² − 1)/(x − 1) behave near x = 1?

Direct substitution gives 0/0 (undefined), but for every x ≠ 1 we can simplify:

(x² − 1)/(x − 1) = (x − 1)(x + 1)/(x − 1) = x + 1

As x → 1, the expression approaches 1 + 1 = 2. Therefore:

limx→1 (x² − 1)/(x − 1) = 2

One-Sided Limits

Left-Hand & Right-Hand Limits

limx→c⁻ f(x) = L — the limit as x approaches c from the left (values less than c).

limx→c⁺ f(x) = L — the limit as x approaches c from the right (values greater than c).

Existence Rule

The two-sided limit limx→c f(x) exists if and only if both one-sided limits exist and are equal:

limx→c⁻ f(x) = limx→c⁺ f(x) = L

// Section 3

When Limits Do Not Exist

A limit fails to exist in three common situations:

1. Jump Discontinuity
Left ≠ Right
The Heaviside step function H(t) has H(t)=0 for t<0 and H(t)=1 for t≥0. limt→0⁻ H(t)=0 but limt→0⁺ H(t)=1. The two-sided limit does not exist.
2. Infinite Limit
Blows up to ±∞
limx→0 1/x² = +∞. The function grows without bound and never settles near any finite number L. We write the limit does not exist (DNE), or say it "equals infinity" informally.
3. Wild Oscillation
No single value
Some functions oscillate infinitely fast near a point (e.g. sin(1/x) near 0), never honing in on one value. The limit DNE.
// Heaviside step function — left and right limits disagree
t→0⁻ = 0 limt→0⁺ = 1 0

Techniques for Finding Limits

Direct Substitution & Limit Laws

Direct Substitution

If f is a polynomial or rational function and a is in the domain of f, then:

limx→a f(x) = f(a)
The Limit Laws

Suppose limx→a f(x) and limx→a g(x) both exist. Then:

LawFormula
Sumlim [f(x) + g(x)] = lim f(x) + lim g(x)
Differencelim [f(x) − g(x)] = lim f(x) − lim g(x)
Constant Multiplelim [c·f(x)] = c·lim f(x)
Productlim [f(x)·g(x)] = lim f(x) · lim g(x)
Quotientlim [f(x)/g(x)] = lim f(x) / lim g(x), if lim g(x) ≠ 0
Powerlim [f(x)]ⁿ = [lim f(x)]ⁿ
Rootlim ⁿ√f(x) = ⁿ√lim f(x)
Example

Evaluate limx→5 (2x² − 3x + 4)

= 2(5)² − 3(5) + 4 = 50 − 15 + 4 = 39

Factorization & Dividing Out

When direct substitution yields the indeterminate form 0/0, factor the numerator and denominator, cancel common factors, then substitute again.

Example — 0/0 Form

Find limx→−3 (x² + x − 6)/(x + 3)

// Factor, cancel, substitute
⟹(x² + x − 6)/(x + 3) = (x − 2)(x + 3)/(x + 3)factor numerator
⟹= x − 2cancel (x + 3), x ≠ −3
⟹limx→−3 (x − 2) = −3 − 2
= −5
More Examples

limx→2 (x² − 4)/(x³ − 8) = lim (x−2)(x+2)/[(x−2)(x²+2x+4)] = lim (x+2)/(x²+2x+4) = 4/12 = 1/3

limx→3 (x² − 9)/(x² − 5x + 6) = lim (x−3)(x+3)/[(x−2)(x−3)] = lim (x+3)/(x−2) = 6/1 = 6

Rationalizing Technique

When a radical appears in the numerator and direct substitution gives 0/0, multiply numerator and denominator by the conjugate of the radical expression.

Example

Find limx→0 (√(x+1) − 1)/x

// Multiply by conjugate √(x+1) + 1
⟹[(√(x+1) − 1)/x] · [(√(x+1) + 1)/(√(x+1) + 1)]
⟹= [(x+1) − 1] / [x(√(x+1) + 1)] = x / [x(√(x+1) + 1)]
⟹= 1 / (√(x+1) + 1)cancel x, x ≠ 0
⟹= 1 / (√1 + 1) = 1/2
lim = 1/2

Limits to Infinity

Rational Functions at Infinity

For polynomials, divide numerator and denominator by the highest power of x in the denominator, then use the fact that limx→∞ 1/xⁿ = 0 for n > 0.

deg(N) < deg(D)
Limit = 0
limx→∞ (x³+3x+6)/(x⁵+2x²+9) = 0
deg(N) = deg(D)
Limit = ratio of leading coefficients
limx→∞ (3x²+2x+1)/(5x²−x+4) = 3/5
deg(N) > deg(D)
Limit = ±∞
limx→∞ (x⁷+4x⁵+2)/(2x⁵+3x²+1) = ∞
Special Limits to Remember

limx→0 eˣ = 1    limx→1 ln x = 0    limx→∞ ln x = ∞

limx→0 (eˣ − 1)/x = 1    limx→0 ln(1+x)/x = 1

Piecewise Functions & Limits

For a piecewise function, always check the left-hand and right-hand limits separately at the boundary points.

Example

Let f(x) = 2 − x if x < 1, and f(x) = x² if x ≥ 1.

Find limx→1 f(x).

// Check both sides
⟹limx→1⁻ f(x) = limx→1⁻ (2 − x) = 1
⟹limx→1⁺ f(x) = limx→1⁺ x² = 1
⟹Both sides agree → the two-sided limit exists
limx→1 f(x) = 1
Important

If the left and right limits had been different, the two-sided limit would not exist even though each one-sided limit exists individually.
